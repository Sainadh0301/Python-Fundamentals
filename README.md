# 🐍 Python Fundamentals 

## 📌 About the Project

This repository contains solutions to **Python&#x20;**, focusing on `while` loops, `for` loops, control statements, and functions.

Three simple Python programs designed to strengthen programming fundamentals and logical thinking.

## 📂 Projects Included

### 1. 🎯 Number Guessing Game

A simple game where the computer generates a random number between 1 and 10, and the user tries to guess it within three attempts.

**Concepts used:**

* `while` loop
* `if`, `elif`, and `else`
* `break` and `continue`
* `while-else`
* `random.randint()`

**Run the program:**

```bash
python number_guessing_game.py
```

### 2. ✖️ Multiplication Table Generator

Generates the multiplication table from 1 to 10 for a number entered by the user.

**Concepts used:**

* `for` loop
* `range()`
* User input
* Arithmetic operations
* Formatted strings

**Run the program:**

```bash
python multiplication_table.py
```

### 3. 🧮 BMI Calculator

Calculates Body Mass Index (BMI) using the user's weight in kilograms and height in meters.

**Formula:**

`BMI = weight (kg) / height (m)²`

**Concepts used:**

* Functions
* Parameters and return values
* User input
* Arithmetic operations
* Formatted output

**Run the program:**

```bash
python bmi_calculator.py
```
